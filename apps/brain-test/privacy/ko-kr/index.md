## 기기에서 처리하는 정보

입력한 이름과 선택한 성별로 재미를 위한 뇌구조 결과를 기기 안에서 만듭니다. 의학적·심리학적 진단 서비스가 아닙니다. 이름, 성별, 당일 결과와 광고 표시 간격·실험 그룹 정보는 기기에 저장합니다. 입력한 이름이나 결과 이미지를 개발자의 서버로 전송하지 않으며 이름을 분석 이벤트에 넣지 않습니다. 사진 저장은 사용자가 요청할 때 사진 권한을 사용합니다. 공유 시 선택한 앱으로 이미지가 전달되며, 해당 서비스의 정책이 적용됩니다.

## 광고·분석·설정 서비스

Google AdMob은 광고 제공, 광고 성과 분석, 부정 사용 방지를 위해 IP 주소(대략적인 위치 추정에 쓰일 수 있음), 앱·광고 상호작용, 진단 정보 및 허용된 기기 식별자를 처리할 수 있습니다. 비개인화 광고도 이러한 데이터 처리가 발생할 수 있습니다. 앱에서 GPS 위치를 요청하지 않습니다.

Google Analytics for Firebase에는 앱 설치·이용 식별자, 기기·앱 정보, 화면 이용, 선택한 성별 구분, 언어, 결과 저장·공유 동작, 광고 노출·수익과 실험 그룹 같은 이용 정보가 전달될 수 있습니다. 계정 가입이나 결제 기능은 없습니다. Firebase Remote Config는 광고 설정을 전달하며 Firebase 설치 식별자와 연결 정보 등을 처리합니다. 분석 수집을 꺼도 설정을 위한 통신은 발생할 수 있습니다.

1.9.4부터 앱은 비개인화 광고를 요청하며 Firebase 분석의 광고 개인화·광고 식별자 수집을 끕니다. Google UMP에서 광고 요청 가능 여부와 동의 상태를 확인하고 분석 수집을 설정합니다. 동의가 필요하지 않다고 판단되는 지역에서는 분석 수집이 활성화될 수 있습니다. 필요한 지역에서는 동의 안내와 개인정보 선택 메뉴를 제공합니다. 이전 버전의 설정·화면은 다를 수 있으므로 최신 버전을 사용해 주세요.

## 제공받는 곳과 국외 처리

위 정보는 Google의 AdMob, Analytics 및 Firebase 서비스에서 처리됩니다. 서비스 제공 및 광고·분석·보안 목적으로 앱 이용 시 네트워크를 통해 미국 등 Google이 서버를 운영하는 국가로 전송·처리될 수 있습니다. Google의 처리 조건, 보안 및 보유 정책은 아래 공식 안내를 참고해 주세요. 문의나 권리 행사는 운영자에게 요청할 수 있습니다.

## 보유기간과 삭제

2026년 9월 9일 확인한 이 앱의 GA4 설정은 이벤트 데이터 2개월, 사용자 데이터 14개월이며 새 활동 시 사용자 데이터 보유기간이 갱신됩니다. 이는 모든 집계 보고서나 AdMob 자료의 삭제 기한을 뜻하지 않습니다. Google의 집계 자료·광고·보안 기록에는 해당 서비스의 보유 정책이 적용됩니다. Remote Config 설치 식별자는 Firebase 정책에 따라 처리됩니다.

기기 저장 정보는 앱 삭제 또는 운영체제에서 앱 데이터를 삭제하여 제거할 수 있습니다. 직접 저장한 사진과 공유한 결과는 저장·공유한 서비스에서 별도로 삭제해 주세요. 지원 메일과 첨부 자료는 문의 처리에 필요한 범위에서 사용하며, 처리 완료 후 더 이상 필요하지 않으면 삭제합니다. 법령상 보관 의무가 있으면 해당 기간을 따릅니다.

## 선택과 문의

앱 메인 화면에 개인정보 선택 메뉴가 제공되면 광고 동의를 다시 확인하거나 변경할 수 있습니다. 운영체제에서도 광고 식별자·사진 접근 권한을 관리할 수 있습니다. 광고 설정 확인에 실패해도 결과 생성 기능은 사용할 수 있습니다. 열람·정정·삭제·처리 제한 등의 요청은 위 이메일로 보내 주세요. 계정이 없는 서비스여서 특정 기기의 분석 기록을 바로 식별하지 못할 수 있으며, 가능한 확인 방법과 처리 범위를 안내합니다. 선택을 거절하거나 광고를 제한하면 광고 이용이 달라질 수 있습니다.
