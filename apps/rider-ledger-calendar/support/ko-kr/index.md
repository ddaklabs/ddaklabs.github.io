라이더 장부를 이용해 주셔서 감사합니다. 이 앱은 사용자가 직접 기록하는 독립적인 장부이며 배달 플랫폼 계정과 자동으로 연결되지 않습니다.

## 자주 묻는 질문

### 국가를 바꾼 뒤 기록이 사라졌어요

기록은 국가와 통화별로 분리됩니다. 설정에서 기록을 입력했던 국가로 다시 변경해 주세요. 서로 다른 국가의 기록을 자동으로 환전하거나 합치지 않습니다.

### 금액이나 월간 합계가 이상해요

선택한 국가·통화, 수입·지출 구분과 날짜를 확인하고 필요한 기록을 수정해 주세요. 세금과 순수익은 입력값과 설정한 비율을 바탕으로 한 참고용 추정치이며 공식 세무 조언이 아닙니다.

### 백업과 복구는 어떻게 하나요?

기록은 먼저 휴대전화에 저장됩니다. 처음 클라우드 백업을 선택하면 고유한 백업 ID를 만들고 복구용 사본을 업로드합니다. 백업이 완료된 뒤 표시되는 ID는 다른 사람이 알 수 없게 별도로 보관하세요. 복구는 현재 기기 장부를 백업 내용으로 교체하므로 두 버전이 모두 필요하다면 먼저 파일 백업을 만드세요.

JSON 파일로 내보내 직접 보관할 수도 있습니다. 파일을 임의로 편집하지 마세요.

### 휴대전화를 바꾸거나 분실했어요

라이더 장부를 설치한 뒤 보관한 백업 ID로 복구하거나 이전에 내보낸 JSON 파일을 가져오세요. DDak Labs는 잊어버린 백업 ID로 이용자를 식별하거나 ID를 찾아드릴 수 없습니다.

### 광고 개인정보 선택을 변경할 수 없어요

Google이 개인정보 선택을 요구하는 지역에서만 해당 메뉴가 표시됩니다. 표시되지 않으면 기기에서 제공하는 개인정보·광고 설정을 이용해 주세요. 앱은 비개인 맞춤 광고를 요청합니다.

### 번역 오류는 어떻게 신고하나요?

**설정 → 번역 오류 신고**를 선택하세요. 작성되는 이메일에는 선택한 국가와 언어가 포함됩니다. 보내고 싶지 않은 내용은 삭제할 수 있습니다.

### 클라우드 백업 삭제는 어떻게 요청하나요?

앱 안에서는 클라우드 백업을 삭제할 수 없습니다. 백업 ID와 함께 [ddaklabs@gmail.com](mailto:ddaklabs@gmail.com?subject=%5B%EB%9D%BC%EC%9D%B4%EB%8D%94%20%EC%9E%A5%EB%B6%80%5D%20%ED%81%B4%EB%9D%BC%EC%9A%B0%EB%93%9C%20%EB%B0%B1%EC%97%85%20%EC%82%AD%EC%A0%9C%20%EC%9A%94%EC%B2%AD)으로 요청해 주세요. 삭제 전에 요청 확인에 필요한 정보를 추가로 확인할 수 있습니다.

## 기본 문제 해결

1. App Store 또는 Google Play에서 최신 버전인지 확인합니다.
2. 앱을 완전히 종료한 뒤 다시 실행합니다.
3. 저장 공간과 인터넷 연결을 확인합니다.
4. 앱 재설치나 데이터 삭제 전에 백업 ID를 보관하고 최신 클라우드 또는 파일 백업을 만듭니다.
