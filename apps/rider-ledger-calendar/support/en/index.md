Thank you for using Rider Ledger. The app is an independent manual record-keeping tool and is not connected to delivery-platform accounts.

## Frequently asked questions

### My records disappeared after changing country

Records are separated by country and currency. Open Settings and switch back to the country where you entered them. The app does not convert or merge records from different countries automatically.

### An amount or monthly total looks wrong

Check the selected country, currency, income/expense type, and date. Edit the record if needed. Tax and net-income figures are estimates based on the values and rate you enter, not official tax advice.

### How do backup and restore work?

Your records are stored on the phone first. Keep the backup ID private and write it down. Choose cloud Backup to update the recoverable copy. Restore replaces the current local ledger with the selected backup, so make a file backup first if you need both versions.

You can also export a JSON backup file and store it in a location you control. Do not edit the file manually.

### I changed or lost my phone

Install Rider Ledger and restore using your saved backup ID, or import a previously exported JSON file. DDak Labs cannot identify or recover a forgotten backup ID for you.

### I cannot change advertising privacy choices

The privacy-options entry is available only where Google requires it. If it is not shown, use the privacy and advertising controls provided by your device. Ads are requested as non-personalized ads.

### How do I report a translation problem?

Use **Settings → Report translation issue**. The email draft includes your selected country and language; remove any information you do not want to send.

## Basic troubleshooting

1. Update Rider Ledger from the App Store or Google Play.
2. Close and reopen the app.
3. Check available storage and network access.
4. Before reinstalling or clearing app data, save the backup ID and create a current cloud or file backup.
